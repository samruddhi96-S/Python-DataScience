# Python & Data Science Fundamentals - Practice Project

Yeh project Codomax Digital Internship - Module 01 (Python & Data Science Fundamentals) ke liye banaya gaya hai.

## Project Structure
- `01_variables_and_datatypes.py`: Variables, Data Types, and Type Casting
- `02_loops_and_conditionals.py`: `if-else` conditions, `for` and `while` loops
- `03_functions.py`: Custom functions, parameters, and return values
- `04_lists_and_dictionaries.py`: List operations, Dictionary methods, and manipulation
- `05_file_handling.py`: Reading and writing text files (`sample.txt`)
- `06_data_science_intro.py`: Basic data manipulation with Pandas & NumPy

## VS Code me kaise run karein:
1. Is zip file ko extract / unzip karein.
2. VS Code open karein aur **File -> Open Folder** karke is folder (`Python_DataScience_Practice`) ko select karein.
3. Kisi bhi `.py` file ko open karein aur top-right par Play button (▶) daba kar run karein, ya terminal me execute karein:
   ```bash
   python 01_variables_and_datatypes.py
   ```
